# 🐳 Docker Nginx Laboratory
A professional showcase of containerized web hosting on Linux.

## 🚀 Overview
This repository contains the configuration for a custom Nginx web server deployed on a **Pro-Server (Ubuntu 24.04 LTS)** using Docker volumes for persistent data management.

## 🛠️ Tech Stack
* **OS:** Ubuntu 24.04 LTS (Linux Kernel 6.8.0)
* **Runtime:** Docker Engine
* **Web Server:** Nginx (Latest)
